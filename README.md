# Reasoning Lab (lite)

**Think first. Compare second.** Solve a short logic, debugging, or community-planning
problem and explain your approach. Your first response is locked. Then you see:
- a rule-based check of your answer;
- a hand-written **reference explanation** and its answer check;
- a side-by-side comparison showing, with exact quotes, which requirements each explanation stated.

## Features

- 12 original problems (4 logic, 4 debugging, 4 community planning), including matched variants. Every valid answer is accepted.
- Guest sessions with no personal details, and a draft that autosaves on the device.
- **Atomic lock** of the first response. Double submits can’t create two responses, and locked text can’t be edited, 
- Results:
  - answer check;
  - “What you noticed” / “What the reference added”
  - a requirement-by-requirement table
  - highlighted quotes side by side
  - a dispute button on every finding
  - separate revisions.
- My activity, with delete-everything.


## Quick start (Windows PowerShell, macOS, or Linux)

```bash
# needs Node 20.18+ and PostgreSQL 16 (Windows: winget install -e --id PostgreSQL.PostgreSQL.16)
npm install
npm run setup:local
npm run dev            # → http://localhost:3000
```

## Honest labelling

The reference explanations were written by the project team in the style of an AI
explanation. Some are deliberately wrong. The app labels them as hand-written, not
AI-generated. The comparison is keyword matching, so findings are marked provisional,
and “not stated” never means “didn’t think of it”.
